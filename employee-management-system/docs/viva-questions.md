# AIP Viva Questions

**Why MVC?** It separates presentation, request handling, and database logic, making the system easier to test and maintain.

**Why PreparedStatement?** It binds values safely and reduces SQL injection risk.

**What is a session?** A server-side mechanism that remembers the authenticated administrator across requests.

**Why use BCrypt?** It stores a one-way salted password hash instead of plaintext credentials.

**Difference between forward and redirect?** Forward stays inside the server request; redirect sends a new request from the browser.

**What does the DAO do?** It centralizes JDBC queries and maps ResultSet rows to model objects.
